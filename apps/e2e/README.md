# Browser E2E (`@guardedsleep/e2e`)

Playwright tests that spin up **two Chromium instances** (baby + parent) against `pnpm run dev:local` (see root `package.json`). Audio input uses Chromium fake devices and WAV fixtures under `tests/fixtures/` (generated by `pnpm run generate-fixtures`).

## Prereqs

- Node 22+, pnpm 9.15.4
- `pnpm install` at repo root (installs Playwright in this workspace)
- First run: `pnpm --filter @guardedsleep/e2e exec playwright install chromium` (CI uses `--with-deps`)

Playwright starts `pnpm run dev:local` with **`PORT=18787`** for the signaling server so it does not fight a developer stack on **8787**. Deep links and `localStorage` (`guardedsleep:signaling-url`) are aligned via `E2E_SIGNALING_URL` set in `playwright.config.ts`.

To reuse an already-running dev stack (you must use the **same** signaling port as in `E2E_SIGNALING_URL`), set `PW_REUSE_EXISTING_SERVER=1` when running Playwright.

## Commands

```bash
pnpm run e2e                 # from repo root
pnpm --filter @guardedsleep/e2e test
```

With visible browsers (local debugging):

```bash
HEADLESS=0 pnpm --filter @guardedsleep/e2e test
```

## Coverage (high level)

- **01–04:** Signaling + WebRTC connect, paste-invite / `pair_proof`, inbound audio after Listen, latency stats (log only).
- **05:** Sustained loud input → parent receives `noise_alert`.
- **06:** Silence + moderate gate (`0.05` / `800 ms`) → **no** `noise_alert` for 9 s.
- **07:** `blip-50ms.wav` (50 ms full-scale spike) + `holdMs` 500 ms → **no** alert (hold not satisfied).
- **08:** After **Listen** off, baby **outgoing audio track is disabled** (`getE2eBabyLocalAudioTrackEnabled`); inbound RTP counters are not asserted (browser may still report buffered packets).
- **09:** `(re)start session` on both sides → **connected** + open DataChannel again.
- **10:** Noise alert → parent `<audio>` has **`srcObject`** with an audio track (playback wiring).
- **11:** Pasted invite with **corrupted PSK** → **failed** on baby or parent (`pair_proof` mismatch).
- **12:** Deep link with **unreachable** signaling URL → **failed**.

## Dev-only hooks

The mobile app exposes `window.__guardedsleep_test` **only** when `import.meta.env.DEV` is true (Vite dev server). Production static builds must not contain this surface — see [ADR-007](../../docs/decisions/ADR-007-browser-e2e-test-strategy.md). On the **parent** route, counts of `noise_alert` handler invocations are available for E2E (`getNoiseAlertCount` / `resetNoiseAlertCount`).

## Privacy

Do not upload Playwright traces that contain pasted invites / session pairing material to public trackers. CI retains traces only on failure as artifacts.
