Base C "Warm Adaptive", calmed with A, status bar and stage progress from B. Mockup: `mockup.html` (54 frames, tokens, EN/DE copy table), generated by `gen.py` + `gen_css.py` + `gen_table.py` (`render.sh` re-renders).

## Owner decisions (2026-11-14)

1. **Role names:** keep "Parent device" / "Baby device" for alpha; Home sub-lines and person names on the baby side soften them. Revisit after alpha feedback.
2. **Start default:** "Ask every time" stays the default; the last-used connection is one tap on Home; opening it directly is chosen in Settings › Open at start.
3. **Night mode in alpha:** Off · On · Automatic with the **time window only**; the light sensor goes to the backlog. Safety colours stay exempt.
4. **Vibrate-only reminder:** one line on Home when starting with Vibrate only; no next-morning reset, no new alert behaviour (backlog item).
5. **Hearing tone name:** "Low", tagged "Hard of hearing".
6. **Talk-back in the browser:** full support as decided in `add-talk-back` (owner, 2026-11-11). The browser parent shows **Hold to talk** exactly like Android, with the same states (frames 32–34); keyboard: Space held; accessible alternative "Talk for up to 30 s"; a talk ends when the page goes to the background.

## 1. Principles

1. **Calm by default, unmistakable when it matters.** Connected = neutral; a coloured bar always means a change; alert slabs are dimmed so they don't light the room.
2. **People words, neutral person.** "The child"; stages named by what the phone does.
3. **Never colour alone.** Colour + glyph + words; shape at the loud stage and on the baby unit.
4. **Each state is said once.** A banner is the single statement; information is never drawn as a disabled button.
5. **Nothing looks calm while nothing is monitored** (mic silent, stopped, no connection hide "All quiet").
6. **Thumb zone, one hand.** Listen is a tap toggle; Talk is the only hold (spec). Targets ≥ 48 dp.

## 2. Tokens

Schemes: **Dusk** (default; bg `#141218`, primary `#C9BCEB`), **Day** (white cards with 1 px `#E0D8DF` border on `#FAF7F4`, scrim `rgba(31,27,35,.32)`), **Ember** night mode (bg `#000`, text `#C98A7A`, variant `#A87365` 5.0:1, outline `#9A5E50` 3.6:1; dimness via backlight). Safety roles outside `ColorScheme`: info blue, warn orange, alert red, caution yellow, ok green (dot only when calm). Fixed palettes: noise `#250A10` / slab `#7A1E30`; no connection `#2A0709` / slab `#8C1D24`; loud alarm `#3A080B` + hazard band / slab `#951E27`; baby battery critical amber `#1F1209` / slab `#7A3D12`. Slab text ≥ 7.4:1; the 2 px light border is mandatory. Baby kiosk text `#7D7671` (4.7:1). No non-safety element within ±20° of a safety hue; brand apricot only in the logo.
Type: Plus Jakarta Sans, tnum; 12 (caps labels) / 14 (floor) / 15 / 16 / 20 / 28 / 52 (counters). Motif: the horizon line (logo, hairline under the status bar and Home header, the monitor's sound strip with "A sound above this line sends an alert").

## 3. Structure

```
Home (role headers, ≤ 2 connections each, "Start") ──▶ Parent monitor │ Baby kiosk
 └ ⚙ Settings: Connections (read-only while monitoring) · This device (Alerts, Sound detection,
   Display, Open at start, Check setup, Language, About, Advanced)
Browser parent: same monitor and dock (incl. Hold to talk); adds the sound gate, keep-page-open banner, background warning, Black screen; no Vibrate-only chip.
Monitor: status bar · tools [Alert ▾][☾][⚙] · hero line · sound strip · meta line
         dock: Listen (tap) · Hold to talk · Pause noise alerts · More (sheet; Stop monitoring apart, confirm)
No switching while monitoring: Stop monitoring (confirm) → Home → choose.
```

Tool row: ⚙ laid out first, fixed; night icon-only when off, icon + On/Auto when on, icon-only above 1.15×; alert chip ellipsizes, icon-only while its banner shows, labelled again when that banner is folded. At ≥ 1.5× the chip takes row 1, night + ⚙ right-aligned on row 2; traversal order status → alert → night → settings. If height < 600 dp at ≥ 1.5×, only the status bar and Listen stay pinned and the rest of the dock scrolls.

## 4. Connection states (colour from the core level only)

| Level | Parent | Feedback |
|---|---|---|
| 0, 0–20 s | blue bar "Connecting · Nursery" / "Reconnecting · Nursery — Short drops are normal" | none |
| 1, 20–60 s | orange bar (2 px outline) "Can't reach Nursery — Still trying" + one line; first connect "Not connected yet" | quiet notification |
| 2, ≥ 1 min | red full screen | vibration, soft tone every 10 s |
| ack | red, "Comes back at 03:17 if still no connection" | silent until ack + 5 min |
| 3, ≥ 3 min | red + hazard band "Still no connection to Nursery" | loud alarm, alarm stream |
| restored | card until OK, "Monitoring was interrupted for 1 min 48 s" + missed sounds | notification |

**Red template:** flat strip · label ("Your phone is vibrating" / "Loud alarm sounding" / "Alarm paused") · headline · counter with label below · one sentence with the next stage and its time ("Loud alarm in 2 min (01:07) if still no connection") · decorative progress segments with "Phone vibrating now" · cause card (cause line, step 1 visible, Try now, "More steps" folded) · quiet "Stop monitoring" text button at the end. "I'm checking" is the only filled, pinned action. Causes: `peer_absent` "The baby device isn't online", `server_unreachable` "This phone has no internet", `media_blocked` "The connection is blocked on this network".

**Banners:** order security › mic silent › readiness › baby battery critical / unplugged › weak connection › Pause › Vibrate only; max 2 + "+N more" link. **Baby marks:** 44 × 6 dp bar = fine; dashed top edge = level 1; 5 dp frame, 4 s pulse = level ≥ 2; bar + 10 dp square + "Needs attention" = battery/charger. During a talk only the talk indicator shows.

## 5. Alarm tones and night mode

Picker: Classic (default, today) · **Low** ("Hard of hearing", deep slow beeps ≈ 400–500 Hz) · Beacon · Rising (stepped) · Chime. Play = soft then loud at reduced volume, becomes Stop; "Test connection alarm" warns "full alarm volume, about 8 s"; a real alert stops any preview. **Night mode** (Ember): Off by default; Automatic = time window only in alpha; a manual change wins until the next automatic change; never applies to alerts, the bar from level 1, warning banners, grey/red bar states or safety chips (they keep the fixed Dusk palette; "stopped" stays grey). **Black screen** (web): black cover, first tap shows status, second closes, any alert replaces it.

## 6. Accessibility and interaction

- Alerts: scrolling body + pinned action; counter drops to Headline above 1.5×; evidence frames 46/47; fontScale 2.0 snapshots of 03, 08, 12, 13, 26 are a gate item.
- Alert entry: focus to the headline; strip and caps label hidden from accessibility, so nothing is said twice; focus returns on close.
- Live regions: stage text only; timers and countdowns (alert counters, talk time, "dims in 45 s") excluded and labelled in words; talk speaks only its 5 s warning.
- Disclosure "More steps": button with expanded state, focus to the first step when opened. Icon-only chip: "Alerts for sounds: Vibrate only, Change". "+N more": "2 more notices: …".
- Gesture alternatives: Listen toggle (`stateDescription`), Talk custom action "Talk for up to 30 s", kiosk "Unlock" action with confirm, sheets with visible Close and `Dismiss`.
- Back: monitor → background, never stops; full-screen alert → nothing; sheet → close; settings → monitor. Web: confirm before leaving while monitoring.
- Stop confirm opened from a red screen silences and acknowledges nothing; Keep monitoring / back / scrim return to the alert unchanged.
