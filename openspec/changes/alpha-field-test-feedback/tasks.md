## 2. Noise gate tolerates pauses (core)

- [x] 2.1 Goal: design §1 sliding-window gate in `crates/guardedsleep-core/src/noise.rs`: each sample covers `min(dt, 1000 ms)`; ring buffer over the last `hold` ms; a noisy stretch starts at the first loud sample and ends after 2 s without one; loud on a sample ≥ threshold when the stretch lasted ≥ hold and loud coverage ≥ hold/2; quiet after 2 s without a loud sample; `restart_hold` clears the buffer and sets `last_loud = now`; `Loud` carries the triggering rms (≥ threshold). Constants in the core policy/config with invariants checked where `LinkConfig` invariants are checked. Lower the threshold limit to 0.0015 through **one shared constant** used by `protocol.rs` (`DeviceStatus` parse, today `0.01..=1.0`), `link.rs` clamps, conformance/negative vectors, and expose it to the clients via the bindings. Layer: core only, sans-IO (time comes in as `now_ms`). Acceptance: unit tests for slam (no event), continuous cry (event at hold, not before), continuous 4 s sound at hold 5 s (no event), a 3 s coughing fit then quiet (no event), talking with 0.5 s pauses for 6 s (event), knocks below half coverage (no event), 1 s sample cadence with continuous cry (event), release after 2 s, restart_hold during a loud gate (no instant release); proptests "≥ hold of continuous loud fires within hold + one sample whatever came before" and "the gate never goes loud before hold has passed since the stretch started"; vector test that a `DeviceStatus` with threshold 0.0018 parses and one with 0.001 is rejected; existing tests updated, not deleted.
- [x] 2.2 Heartbeat `loud`: the baby's heartbeat carries optional `loud: bool` (`gate.is_loud()`, default false when absent, validated like every field); the parent core counts a heartbeat as loud when `loud || rms ≥ threshold` for the noise-event keep-alive (`link-supervision` "Noise event lifecycle in the core"); the existing `noise_paused` guard during a talk pause covers `loud` too, so the parent's own talk never keeps the event alive. Acceptance: protocol round-trip and negative tests; `tests/link_pair.rs` cases "pause ends during crying in bursts" (alerts) and "snooze ends during a talk" (no alert from `loud`).
- [x] 2.3 `AcknowledgePeerStopped` core input: stops the parent link only while `peer_stopped`, ignored otherwise; exposed through `ffi` and `wasm`. Acceptance: core tests for both scenarios of `link-supervision` "Acknowledging a deliberate stop".
- [x] 2.4 Simulation and bindings: re-bless vectors/traces; add `guardedsleep-sim` scenarios "talking with pauses", "TV at 30–40 % loud time then crying", "white noise steady at the threshold", "single door slam", "pause ends during crying in bursts"; the log canary must pass; `just api-snapshot` after the binding changes and review the `api.txt`/`core.d.ts` diff.
